# AI 미션코스

AI 미션코스에서는 직접 코드를 작성하며 데이터 준비부터 모델 학습, 평가, 활용까지 경험합니다.

### 학습 대상

Python 기본 문법과 AI의 기본 이론은 알고 있지만, 실제 프로젝트와 Keras를 활용한 모델 구현은 처음인 수강생을 대상으로 합니다.
이론으로 배운 내용이 코드에서 어떻게 쓰이는지 궁금하거나, AI 프로젝트를 어디서부터 시작해야 할지 막막하다면 미션을 하나씩 수행해봅시다.

### 진행 방식

데이터 준비부터 모델 학습과 평가, 활용까지 주차별 미션을 따라 단계적으로 진행합니다.
각 단계에 필요한 이론을 살펴보고 직접 코드를 작성합니다.
제공된 검토 코드를 실행해 결과를 확인하고, 그 의미를 해석해봅시다.

기초적인 모델 구현에서 시작해 사전학습 모델의 활용으로 범위를 넓혀갑니다.
각 단계가 하나의 프로젝트로 어떻게 이어지는지 함께 살펴봅시다.

### 학습 목표

미션코스의 목표는 **초심자가 실전적인 코드를 직접 작성하며 이론을 학습하고, 프로젝트를 진행할 기본 역량을 갖추는 것**입니다.

- 데이터 준비, 모델 학습과 평가, 활용으로 이어지는 전체 흐름을 이해합니다.
- 실행 결과를 바탕으로 모델의 성능과 한계를 설명하고, 다음에 무엇을 개선할지 생각해봅니다.
- 프로젝트에서 부족한 지식을 스스로 찾아 배우고 적용할 수 있는 토대를 만듭니다.

### 주차별 학습 내용

| 주차 | 학습 내용 | 활용 도구 | 주요 결과물 |
|---|---|---|---|
| 1주차 | 리뷰 데이터 분리, 정제, 벡터화 | scikit-learn, Python re, Keras TextVectorization | 학습, 검증, 테스트 데이터와 전처리 설정, 길이 그래프 |
| 2주차 | 감정 분류 모델 학습과 평가, 학습 곡선과 과적합 비교 | Keras Embedding, Pooling, Dense | 학습한 모델, 학습 곡선, 예측과 실패 사례 |
| 3주차 | BERT와 사전학습 이해, 배송과 환불 문서를 검색하여 답변하는 RAG | Transformers, FAISS, Qwen | 검색 근거, RAG 적용 전후의 답변 비교 |
| 4주차 | BERT 파인튜닝, 모델 저장과 복원, API로 예측 결과 제공 | Transformers, FastAPI | 저장한 모델과 tokenizer, API 호출 결과 |
